# PowerAutomateToExcel

Power Automate のフロー定義（`definition.json`）を Excel のフロー設計書に変換する [Office スクリプト](https://learn.microsoft.com/ja-jp/office/dev/scripts/) です。

エクスポートした JSON を Excel に貼り付けてスクリプトを実行するだけで、トリガー・アクションの階層構造、分岐ルート、入力パラメーター、実行条件（runAfter）が一覧化された「フロー設計書」シートが生成されます。

## 特徴

- **実行順に並べ替え** — `runAfter` の依存関係を解析し、実際の実行順でアクションを並べます
- **階層と分岐ルートを可視化** — スコープ / 条件分岐 / ループ / スイッチの入れ子を `Root > 親アクション > ...` の形式で表現します
- **分岐が一目で分かる色分け**
  | 種類 | 色 |
  | --- | --- |
  | 条件分岐（True 側） | 緑 `#E2EFDA` |
  | 条件分岐（False 側） | 赤 `#F4CCCC` |
  | Scope（スコープ） | オレンジ `#FCE4D6` |
  | Foreach / Until（ループ） | グレー `#F2F2F2` |
- **ループ / 分岐の設定値も出力** — `inputs` を持たない Apply to each（繰り返し対象）、Do until（終了条件・制限）、スイッチ（判定対象）の設定値も補完して出力します
- **トリガーの詳細も出力** — スケジュールトリガーの `recurrence`（繰り返し設定）や、コネクタの `operationId` も併記します
- **外部ツール不要** — Excel on the web / デスクトップ版の Office スクリプトだけで完結します

## 使い方

1. Power Automate でフローを **zip でエクスポート** します
   （フローの一覧 → 対象フロー → 「エクスポート」→「パッケージ (.zip)」）
2. zip 内の `definition.json` を開き、**テキストを全文コピー**します
3. Excel で **`JSON` という名前のシート**を作成し、**A1 セル**にコピーしたものを貼り付けます
4. 「自動化」タブから本スクリプトを実行します
5. **`フロー設計書` シート**が新規作成され、フローの内容が出力されます

> [!NOTE]
> `フロー設計書` シートが既に存在する場合、**削除してから作り直されます**。手を加えた設計書を残したい場合は、実行前にシート名を変更するかブックを複製してください。

## 導入方法

1. Excel（Web 版またはデスクトップ版）で「自動化」タブ →「新しいスクリプト」を選択します
2. コードエディターの中身をすべて削除し、[PowerAutomateToExcel.ts](PowerAutomateToExcel.ts) の内容を貼り付けます
3. 任意の名前を付けて保存します

## 出力される列

| 列 | 内容 |
| --- | --- |
| No | 出力順の通し番号 |
| 階層 / 分岐ルート | `Root > スコープ名 > 条件名 [◯ True]` のような、そのアクションが属する経路 |
| アクション名（変更後） | フロー上で設定されているアクション名 |
| 種類 / デフォルト名 | アクションの `type`。コネクタの場合は `operationId` を併記 |
| 入力パラメーター（inputs/条件など） | `inputs`（または `parameters`）を整形した JSON。条件分岐・スイッチ・Do until は `【条件式】`、Apply to each は `【繰り返し対象】`、Do until の上限は `【制限】`、スケジュールトリガーは `【スケジュール設定】` を付与。設定値がない場合は `-` |
| 実行条件（runAfter） | 直前のアクション名と、その実行結果（`Succeeded` / `Failed` など） |

## 動作環境

- Excel on the web、または Microsoft 365 デスクトップ版 Excel（Office スクリプト対応プラン）
- OneDrive for Business / SharePoint に保存されたブック

## 注意事項

- **JSON には接続情報やパラメーターの既定値が含まれる場合があります。** 社外に共有するブックを作成する際は、出力内容に機密情報が含まれていないか確認してください。
- Excel の 1 セルには **32,767 文字**の上限があります。`inputs` が非常に大きいアクションでは、内容が切り捨てられる可能性があります。
- 本スクリプトは Office スクリプトの実行環境（`ExcelScript` 名前空間）を前提としているため、Node.js や `tsc` 単体ではコンパイルできません。
